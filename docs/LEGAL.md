# 법적 검토 체크리스트

이 문서는 법률 자문을 대체하지 않습니다. 정식 출시 전 반드시 변호사 검토가 필요합니다.

## 1. 통신비밀보호법
- 동의 없는 타인의 문자/통화 내용 감청·열람은 형사처벌 대상 (3~10년 이하 징역)
- **필수 조치**: 온보딩 시 피감독자 본인이 직접 계정을 만들고 권한을 승인하는 구조. 보호자가 원격으로 설치·동의 처리 불가
- 문자 원문은 저장하지 않고 키워드 매치 여부만 전송 (`docs/ARCHITECTURE.md` 참고)

## 2. 개인정보보호법
- 위치, 앱 사용 이력, 방문 사이트 등은 민감/행태 정보 → 개인정보처리방침 게시 필수
- 최소수집 원칙: 목적에 필요한 항목만 수집 (예: 통화 "내용"이 아닌 "번호+시간"만)
- 전송 구간 TLS 암호화, 저장 시 DB 암호화(pgcrypto 또는 컬럼 레벨 암호화) 적용

## 3. 위치정보의 보호 및 이용 등에 관한 법률
- 개인 위치정보를 서버로 전송·저장하면 **방송통신위원회 "위치기반서비스사업 신고"** 대상 가능성 높음
- 기기 내 처리만 하고 서버 미전송 시 신고 면제 가능성 있으나, 보호자 대시보드에 위치를 보여줘야 하는 이 서비스 특성상 서버 경유가 사실상 불가피 → **출시 전 신고 여부 법무 확인 필수**

## 4. 스토킹범죄의 처벌 등에 관한 법률
- 성인 대상 동의 없는 위치추적/감시는 관계와 무관하게 처벌 대상 소지
- "보호자-피보호자" 관계여도 법적 후견 지위가 없다면 감시의 법적 근거가 약함
- → 반드시 **자발적 회복지원 툴**로 포지셔닝, 동의 철회(옵트아웃) 기능 상시 제공

## 5. Google Play 정책
- SMS/CALL_LOG 권한 그룹은 기본 SMS/전화 핸들러가 아니면 사용 불가 → 이 프로젝트는 해당 권한을 선언하지 않음
- Accessibility API는 "핵심 기능에 필수적인 경우"에만 허용 → Play Console 심사 시 접근성 사용 목적을 명확히 소명해야 함 (Permissions Declaration Form)
- Device Admin API 사용 앱은 자녀/피보호자 보호 목적 명시 필요

## 6. 상표권
- "모바일펜스" 등 기존 서비스명/로고 사용 금지. 프로젝트명은 별도 브랜드(가칭 SafeCircle)로 진행

## 온보딩 동의 플로우 (필수 구현)
1. 서비스 목적/수집 항목 고지 화면
2. 피감독자 본인 전자서명/체크박스 동의 (타임스탬프 + 기기 ID와 함께 서버 저장)
3. 상시 포그라운드 알림: "이 기기는 SafeCircle에 의해 모니터링되고 있습니다"
4. 언제든 동의 철회 및 앱 제거 가능 안내 (단, 철회 시 보호자에게 알림 발송은 별도 협의 필요)
